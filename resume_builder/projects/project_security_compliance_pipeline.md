- **Infrastructure:** Docker

## What It Does
A comprehensive CI/CD security and compliance pipeline built in GitHub Actions that automates static code analysis (SonarQube), container image scanning (Trivy), and secrets detection. Integrated quality gates and security checks into pull-request workflows to block non-compliant merges and enable early issue detection.

## Quantitative
- Automated compliance checks on every pull request
- Container vulnerability scanning via Trivy
- Static code analysis with SonarQube quality gates
- Early detection of secrets and misconfigurations
