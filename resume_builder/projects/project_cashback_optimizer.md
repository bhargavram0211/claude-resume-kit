## Stack
- **Languages:** TypeScript, Python
- **Frameworks:** React 18, FastAPI

- **Infrastructure:** Docker, Docker Compose
- **APIs:** Plaid API

## What It Does
A full-stack web application that helps users optimize their cashback rewards by analyzing real-time transaction data from multiple financial accounts. Integrates with Plaid API for transaction ingestion and uses a rules engine to categorize and optimize spending patterns with 95%+ accuracy using PFCv2 taxonomy.

## Quantitative
- 95%+ transaction categorization accuracy using PFCv2 taxonomy
- Real-time transaction ingestion via Plaid API
- Containerized multi-service architecture with Docker Compose
